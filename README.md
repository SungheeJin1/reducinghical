# 데뷔 프로젝트

고칼로리 식품 줄이기 기록 웹앱. 핑크 궁전 입구에서 토끼가 반겨주며 토막 건강상식을 알려 주고, 문을 열면 오늘의 기록을 입력하며, `기록표 보기`에서 종이 기록표 형식으로 볼 수 있습니다.

`index.html` 하나로 동작합니다. 브라우저에서 바로 열거나 GitHub Pages로 배포하세요. 기록은 이 브라우저(localStorage)에 저장됩니다.

## 손 가위바위보 (`rps/`)

카메라로 내 손 모양(가위·바위·보)을 인식하고, 앱도 동시에 하나를 내서 승부를 가리는 웹앱. `rps/index.html`을 https 주소(GitHub Pages 등)로 열고 카메라를 허용하면 됩니다. 손 인식은 MediaPipe Hand Landmarker로 브라우저 안에서만 처리되고, 영상은 어디에도 전송되지 않습니다.

**숫자 쓰기** 탭: 검지 하나만 펴면(☝️) 손끝을 따라 초록 선이 그려지고, 손가락을 접거나 손을 내리면 펜이 떨어집니다. 다 쓰고 약 1초가 지나면 쓴 숫자(여러 자리 가능, 예: 123)를 읽어 화면에 보여 줍니다. 숫자 인식은 MNIST로 학습한 작은 CNN(`rps/digits.json`, int8 가중치)으로 브라우저에서 직접 계산합니다.
